<h2>Standard ve Extended Mod Farkı: Hangisini Açmalısınız?</h2>

<p><strong>Standard</strong> mod, Gemini 3.5 Flash’ın hızlı cevap vermesi gereken işler için uygundur. Arayüzde veya API tarafında bu mod genelde <strong>minimal</strong> ve <strong>low</strong> düşünme seviyelerine denk gelir.</p>

<p>Şu işler için Standard yeterlidir:</p>

<ul>
  <li>Kısa metin düzeltme</li>
  <li>Basit özet çıkarma</li>
  <li>Müşteri mesajını yanıt taslağına çevirme</li>
  <li>Tek turlu fonksiyon çağrısı</li>
  <li>Basit JSON formatlama</li>
  <li>Hızlı fikir listesi üretme</li>
</ul>

<p>Örnek Standard prompt:</p>



```text
Aşağıdaki müşteri mesajını kısa ve net bir destek yanıtına çevir.

Kurallar:
- En fazla 3 cümle yaz.
- Teknik terim kullanma.
- Kesin çözüm sözü verme.
- Bağlamda kesin veri yoksa tahmin yürütme, "Veri yetersiz" diyerek reddet.

Müşteri mesajı:
[mesajı buraya yapıştır]
```


<p><strong>Extended</strong> mod ise daha karmaşık işler içindir. Bu modda model yanıt vermeden önce arka planda daha fazla muhakeme yapar. <strong>medium</strong> ve <strong>high</strong> seviyeleri özellikle profesyonel kullanımda daha değerlidir.</p>

<p>Extended mod şu işlerde daha iyi sonuç verir:</p>

<ul>
  <li>Kod tabanı analizi</li>
  <li>Refactor planı</li>
  <li>SEO içerik kümeleri</li>
  <li>Finansal veri analizi</li>
  <li>Hipotez testi</li>
  <li>Çok turlu ajan görevleri</li>
  <li>Araç kullanan iş akışları</li>
  <li>Uzun dokümanlardan karar çıkarma</li>
</ul>

<p>Pratik öneri:</p>

<p>Basit işler için <strong>Standard / low</strong>, profesyonel işler için <strong>Extended / medium</strong>, riskli ve çok adımlı işler için <strong>Extended / high</strong> kullanın.</p>

<h2>64K Output Sınırı: Büyük Kod ve Uzun Çıktılar Nasıl Yönetilir?</h2>

<p>Gemini 3.5 Flash’ın güçlü taraflarından biri <strong>1 milyon input token</strong> sınırı. Büyük kod tabanlarını, uzun dokümanları ve kapsamlı veri setlerini modele verebilirsiniz.</p>

<p>Ama çıktı tarafında model tek seferde en fazla <strong>64K output token</strong> üretebilir.</p>

<p>Bu yüzden şu prompt yanlıştır:</p>



```text
Bu projeyi baştan sona refactor et ve tüm dosyaları yeni haliyle yaz.
```

<p>Doğru yaklaşım:</p>



```text

```


<p>Büyük işlerde kullanmanız gereken sabit kural:</p>



```text
64K output sınırını aşmamak için tüm dosyayı yeniden üretme. Sadece değişmesi gereken fonksiyonları, sınıfları veya minimal patch parçalarını ver.
```


<p>Bu kural hem kodda hem SEO planlarında hem de veri analizinde işe yarar. Modeli “her şeyi tek cevapta yazan” bir araç gibi değil, aşamalı çalışan bir uzman gibi kullanmak gerekir.</p>

<h3>Kod Yazdırmak İçin Gemini 3.5 Flash Promptu</h3>

<p>Bu şablon, mikrofon girdileri ve websocket paketleriyle çalışan uygulamalarda <strong>race condition</strong>, <strong>memory leak</strong> ve bağlantı yönetimi hatalarını bulmak için hazırlandı.</p>

<p><strong>Önerilen mod:</strong> <strong>Extended / medium-high</strong></p>



```text
Bir kıdemli yazılım mimarı gibi davran. Amacın tüm projeyi yeniden yazmak değil, riskli noktaları bulup sadece gerekli parçaları düzeltmek.

İnceleyeceğin sistem:
Gerçek zamanlı mikrofon girdilerini işleyen, websocket paketlerini yöneten ve ses akışını sunucuya ileten büyük bir kod tabanı.

Ana hedef:
Kod tabanındaki race condition, memory leak, websocket lifecycle hataları, event listener temizleme eksikleri, kontrolsüz reconnect döngüleri ve kaynak yönetimi problemlerini bul.

Önemli model sınırı:
Gemini 3.5 Flash 1 milyon input token okuyabilir; ancak tek yanıtta 64K output token sınırı vardır. Bu yüzden tüm dosyaları yeniden yazma. Sadece değişmesi gereken fonksiyonları, sınıfları veya minimal patch parçalarını üret.

Muhakeme sürekliliği:
Önceki adımlardaki gizli muhakeme mantığını (thought summary) hafızanda tutarak bir sonraki adıma geç.

Doğruluk kuralı:
Bağlamda kesin veri yoksa tahmin yürütme, "Veri yetersiz" diyerek reddet.

```

```text
const headers = {

  "Authorization": `Bearer ${process.env.GEMINI_API_KEY}`,

```


<p>Daha kontrollü örnek:</p>



```text
function buildGeminiHeaders({ isAgentStep }) {
  const headers = {
    "Content-Type": "application/json",
    "Authorization": `Bearer ${process.env.GEMINI_API_KEY}`
  };

  if (isAgentStep) {
    headers["X-Initiator"] = "agent";
  }

  return headers;
}
```


<p>Bu ayrım özellikle çok turlu ajan sistemlerinde önemlidir. İnsan isteğiyle ajanın arka plan adımı aynı şekilde faturalandırılırsa, küçük bir yanlış sınıflandırma kısa sürede ciddi maliyet farkına dönüşebilir.</p>
